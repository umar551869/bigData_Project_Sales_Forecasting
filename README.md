#Big Data Sales Forecasting with PySpark
Python
PySpark
Machine Learning

This project demonstrates a Big Data Sales Forecasting system using PySpark for processing and machine learning. It analyzes retail transaction data to predict future sales quantities using a distributed computing approach.

#Features
Big Data Processing: Handles large-scale retail data using PySpark

Time Series Forecasting: Predicts sales quantities using Random Forest Regression

Data Visualization: Includes exploratory data analysis with Matplotlib/Seaborn

Feature Engineering: Extracts temporal features (day, week, month, etc.) from timestamps

Model Evaluation: Calculates Mean Absolute Error (MAE) for predictions

#Dataset
The project uses the Online Retail dataset containing:

Transaction data from 2010-2011

500,000+ records

Features: InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country
